# BetterUs motion principles

- **Responsive:** 120–180 ms for press feedback.
- **Supportive:** 220–320 ms spring settling for cards and navigation.
- **Celebratory:** up to 520 ms for meaningful milestones, used sparingly.
- The brand gesture is an upward nested reveal: outer path first, inner path following with a short stagger.
- Respect reduced-motion settings by replacing staged drawing with a static fade.
